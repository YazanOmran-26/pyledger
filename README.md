# pyledger documentation
## How To Use The Program:
1- Inputs do not need to be capitalized in anyway no Inputs will crash the program.
2- Python Language used.
3- Click run and use the instructions on screen that guide you on the basic controls.
## Contents Of Program:
1- Add transactions feature: Adds a transaction whether it be an expense or an income.
2- List/Filter feature: Only shows previously made transaction depending on different criteria WITHOUT editing the transaction.
3- Edit/Delete feature: Allows you to edit a mistake made in a transaction or delete a transaction all together.
4- Summary report: Only shows net balance, total income, total expenses, as well as what you spent your money on.
5- Category Budget feature: Allows you to add a monthly budget for a certain category and will warn you if you overspend.
6- Search: Unfinished
7- Save-Load: Unfinished
8- Export to CSV: Unfinished
9- The Menu Loop: Simply displays the options available
